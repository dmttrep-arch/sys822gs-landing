# Outreach Wave 1 — скрипт дня

Сайт: https://sys822.ru/ · SKU: SYS-822GS-NB3RT-01-G2 · ориентир: **от $1M**, условия по запросу.  
Источник целей: `icp_wave1.csv` · шаблоны писем: `OUTREACH.md` (вариант **A** — интегратор, **B** — CTO/Head of AI).

## Цель волны

- **10 касаний/день** (email и/или LinkedIn InMail/connect+note), 5 рабочих дней ≈ **50** первых касаний.
- Не спам: персонализация 1–2 факта (сегмент, роль, why_fit из CSV).
- Не выдумывать личные email: только корпоративные формы, sales@ / partner@ с сайта, или LinkedIn.

## Приоритет отправки (каждый день)

1. Сначала строки с `notes`, содержащими **Wave1 priority**.
2. Затем `segment=integrator` + `message_variant=A`.
3. Затем `ai_lab` / `gpu_cloud` / `datacenter` + `B`.
4. СНГ и «тип цели» — после закрытия РФ-приоритета.

## Распорядок дня (~60–75 мин)

| Время | Действие |
|-------|----------|
| 0–10 мин | Открыть CSV, выбрать **10** строк со `status=todo`. Записать в дневной лог (ниже). |
| 10–50 мин | 10 касаний: подставить роль/компанию в шаблон A или B; UTM как в `OUTREACH.md`. |
| 50–60 мин | Обновить CSV: `status` → `sent`, в `notes` — дата + канал + кратко что отправили. |
| +15 мин (опц.) | 3–5 follow-up по ответам вчерашнего дня. |

## Правила касания

- **Один** первичный контакт на компанию/роль за волну (не дублировать Softline Digital и Softline в один день).
- Тема письма — как в `OUTREACH.md`; тело ≤ 80–100 слов.
- CTA: «да/нет» (A) или «актуально в 3–6 мес / не сейчас» (B).
- Если нет валидного канала — `status=blocked`, в `notes` причина (нет публичного контакта).
- Не обещать дилерство, наличие на складе, сроки поставки без сверки с sales.

## Трекинг ответов

Колонка `status` в CSV:

| status | Значение |
|--------|----------|
| `todo` | Ещё не отправлено |
| `sent` | Касание ушло |
| `replied` | Любой ответ (в т.ч. «не сейчас») |
| `meeting` | Согласован созвон / техразбор |
| `sql` | Есть роль + горизонт + бюджетный коридор |
| `nurture` | Интерес позже (3–6+ мес) |
| `blocked` | Нет канала / отказ жёсткий / комплаенс |
| `ooo` | Автоответ / отпуск — follow-up через N дней |


### Метрики недели 1

- Sent ≥ 40
- Reply rate цель ≥ 10%
- Meeting ≥ 2
- SQL ≥ 1 (роль + срок + коридор бюджета)

Лиды с формы сайта с UTM `outreach` / `integrator_wave1` / `ai_cto` — сверять с `ANALYTICS.md` / Cloudflare.

## Follow-up

- Нет ответа **+4 раб. дня**: один короткий follow-up (ссылка + «закрыть тему?»); затем `nurture` или стоп.
- «Не сейчас» → `nurture`, дата касания +90 дней в `notes`.
- «Да» / интерес → сразу слот инженера 15 мин (A) или техразбор питание/800G/память (B); `status=meeting`.
